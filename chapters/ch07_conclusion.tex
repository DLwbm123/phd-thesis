\chapter{总结与展望}
\label{chap:conclusion}

\section{全文工作总结}
\label{sec:conclusion-summary}

本文研究医学影像任务持续到达、训练信息不能完整调用时的模型更新问题。全文没有将配准、分割和分类合并为一个损失或一种算法，而是先在第三章建立基准评测、能力分解和平台接口，再依次研究有限回放持续配准、有限回放弱监督持续分割和无回放联邦持续分类。各章共同回答模型如何学习新任务、保持历史能力并形成对未来任务有用的表示，同时明确数据、监督、回放和跨中心共享条件。

第三章以持续医学图像分割为载体建立 Domain-CL、Class-CL 和 Organ-CL 三类场景。统一实验设置明确病例划分、任务顺序、训练预算、输出组织和测试时点；A-Dice 与 BWTR 观察总体性能和旧任务保持，RMA 与 E-FWT 分别补充当前任务建模和未来域直接表现，MPE 与 DRR 说明参数增长和回放代价。结果显示，降低遗忘并不自动提高当前学习或前向泛化。第三章还明确了分割数据向第五章的直接复用，以及评价框架向第四章配准和第六章分类的扩展，并为综合平台定义数据适配、任务编排、方法注册、阶段评价和结果管理接口。

第四章研究有限历史图像对回放下的持续医学图像配准。SAMCL 将经验回放、一阶元持续学习和锐度感知优化结合，在四项器官与模态不同的配准任务中协调当前与历史更新。实验表明，该方法明显减轻了直接顺序训练在早期任务上的性能下降，并在多项预设方向上改善前向泛化；同时，SAMCL 与 MER 的优劣随任务和指标变化，说明有限回放方法仍存在任务相关的稳定性--可塑性取舍。

第五章在第三章相同的数据和测试协议上研究弱监督持续分割。当前训练标签由密集掩膜变为固定涂鸦，ZSDERpp 将全局一致性、空间先验、历史图像--涂鸦回放、参考特征约束和回放弱监督优化结合。六中心 Domain-CL 结果显示，该方法提高了最终平均 Dice 和历史保持，但前向泛化并非最优。该结果进一步说明，监督覆盖、旧任务保护和未来域适用性需要分别评价；Class-CL 与 Organ-CL 的方法适配仍需后续定量验证。

第六章研究原始影像不能跨中心集中、历史原始样本不回放时的联邦持续分类。FedSubMerge 在服务器端融合各客户端主梯度子空间，并通过正交补投影减少后续本地更新对跨客户端历史知识的一阶干扰；FedSubMerge-AD 按层选择相关客户端，为当前任务保留更多更新空间。多组医学影像分类实验揭示统一保护和自适应保护在历史保持与最终准确率上的不同侧重。额外子空间通信只在任务结束后发生，但梯度衍生信息的交换不构成形式化隐私保证。

综上，本文形成三点主要认识。第一，任务变化与训练信息访问必须分别定义，中心变化、稀疏监督、有限回放和跨中心协作不能相互替代。第二，当前任务学习、历史保持和前向泛化相关但不等价，方法比较还应结合参数、回放、计算与通信成本。第三，面向长期使用的医学影像持续学习不仅需要更新算法，还需要可追踪的数据、任务、模型、评价和权限管理；平台建设必须以可运行实现和系统测试为依据，不能由算法结果自动替代。

\section{研究局限性}
\label{sec:conclusion-limitations}

在基准与平台方面，第三章主要采用预先划分的任务、固定主干网络和公开数据。任务顺序与回放容量的补充实验揭示了部分敏感性，但尚未覆盖连续漂移、中心重访、未知类别和多种变化叠加的长期数据流。当前版本完成的是平台需求与接口定义，尚未形成整合全文工作的可运行系统，因此不报告平台吞吐量、并发能力、故障恢复或用户使用效果。

在持续配准方面，SAMCL 依赖容量受限的历史原始图像对。四个顺序任务同时改变器官、模态、个体间或个体内配准关系及损失构成，现有结果不能分离每一种变化因素的独立影响。实验尚未系统交换全部任务次序，也未覆盖更广泛的骨干和形变模型。SAMCL 与 MER 各有占优任务，锐度感知更新不能被解释为所有配准场景中的一致优势。

在弱监督持续分割方面，涂鸦由已有密集训练标签模拟生成，不能代表不同医生的标注习惯、漏标和错标，也不能据此计算真实标注工时节约。密集验证标签仍用于模型选择，因而本文只限制训练监督，并未实现从训练到验证均无需密集标注的流程。目前定量结果仅覆盖 Domain-CL，Class-CL 与 Organ-CL 的性能边界尚未由本章实验确定。

在联邦持续分类方面，FedSubMerge 采用同步任务流、给定任务边界和测试时任务身份，并假设服务器能够接收和融合客户端 PGS。梯度投影只作用于选定共享参数，未投影参数、模型漂移和子空间截断均可能影响旧任务表现。PGS 来源于梯度，其低秩形式不提供形式化隐私保证。现有通信结果反映实验传输量，不包含真实网络时延、连接故障和多服务器调度开销。

在跨任务与应用方面，各章使用不同模态、预测对象和评价单位，因此本文没有给出跨任务的统一方法排名，也没有实现配准、分割和分类的联合持续训练。所有实验均基于回顾性公开数据，尚未完成真实多中心纵向数据流、临床工作流接入、异常处理和人工复核验证。后续平台建设需要把这些工程和治理条件作为独立测试对象。

\section{未来研究展望}
\label{sec:conclusion-future}

\subsection{总体目标：面向新模态、新任务、新中心与新医学知识}

未来工作将从当前的任务特定持续学习扩展到医学多模态大模型的持续学习。总体目标是：面向持续到达的新模态、新任务、新中心和经审核的新医学知识，使模型在吸收新增信息的同时尽量保持既有能力，并在稳定性与可塑性之间形成可测量、可追踪的取舍。图\ref{fig:future-medical-mllm}概括了这一设想。影像与文本先形成共享多模态表征，随后面对胸部 X 线、消化内镜、皮肤镜等不同下游任务的顺序扩展；模型更新既要适应任务和中心变化，也要避免破坏已经建立的跨模态关联与历史任务能力。

这一方向不是简单把现有网络替换为更大的模型。医学多模态大模型同时包含影像编码、文本编码、跨模态对齐、下游任务适配和知识调用等环节，新增数据可能只影响其中一部分，也可能在多个层次引起连锁变化。后续研究需要明确每次更新的对象、可访问历史、评价任务和回退条件，再判断应采用持续预训练、参数高效适配、外部知识更新还是局部参数编辑。基于预答辩提出的框架，未来工作可分为以下三个层次。

\subsection{数据与表征层：持续预训练医学基础表征}

医学多模态基础模型需要在影像、报告和相关结构标注之间形成可复用的表示。数据持续到达后，新设备影像、新模态或新的报告表达可能补充原有训练覆盖，也可能改变旧有影像--文本对应关系。未来可研究在受限历史访问下持续预训练，使模型吸收新资料，同时保留已有器官结构、疾病相关视觉特征和跨模态关联。研究重点不是仅增加模型规模，而是明确哪些表示可以共享、哪些信息需要保留为历史参照，以及新增资料是否造成旧任务能力下降。

这一层次需要建立带时间与来源记录的数据流，区分采集时间、报告版本、患者划分和来源中心。对于影像与报告不完全配对或部分模态缺失的情况，应分别评价单模态能力和跨模态匹配，避免以样本数量增长替代数据质量分析。少量代表性历史样本、旧模型输出或压缩表征可作为知识保持的候选载体，但其存储成本、信息保真与共享限制需要在相同条件下比较。

评价也应从单一预训练损失扩展到固定的历史任务测试和新任务迁移测试。可使用分割、配准与分类等下游任务检查结构表示是否保留，并单独记录影像检索、图文对应等跨模态能力。模型每次更新都应与未更新版本及相同新增数据条件下的直接训练参照比较，同时报告训练步数、显存和保留历史信息的成本。这些实验用于判断持续预训练是否积累了可迁移知识，而不仅是适应近期数据。

\subsection{任务与场景层：参数高效的持续领域适配}

即使基础表征较强，新中心的设备、患者构成、标注协议和下游用途仍可能不同。未来可研究以低秩适配、提示或小型任务模块完成持续领域适配，在保留基础模型主要参数的同时满足新中心需求。本文中的历史特征保持、子空间保护和有限回放提供了可研究的出发点，但将这些机制用于多模态模型前，需要重新确定可训练参数、历史信息载体和任务评价，不能直接沿用小型网络中的最优配置。

这一层次需要处理任务边界未知和中心重复出现的问题。真实数据流可能同时包含旧中心回访、新类别出现和成像条件缓慢变化，模型不能总是依赖预先提供的任务编号选择输出头。未来可研究根据输入和模型不确定性判断是否需要更新、复用已有适配模块或增加新模块，并控制模块数量随时间增长的成本。对于联邦场景，还应区分中心内适应与跨中心共享：适合某个中心的参数更新未必适合所有中心，共享范围需要结合任务相关性与信息访问条件确定。

实验可分别固定基础模型、训练数据量和可训练参数数量，比较完整微调、独立适配与持续适配。除新中心性能外，还应检查旧中心保持、未知中心泛化、模块路由错误和更新开销；对于联邦协作，还需测量通信量与不同客户端参与情况。这样的评价能够判断参数高效方法节约了什么成本，以及是否把遗忘问题转移到了模块选择或模型容量增长上。

\subsection{知识与行为层：持续知识编辑与能力保持}

基础模型长期使用还会面对知识内容和行为要求的修订。例如，数据解释规则、术语定义或经审核的知识条目可能发生更新，这类变化未必需要重新训练全部视觉表征。未来可研究持续知识编辑，在明确修改对象和依据的条件下更新模型知识或输出规则，并减少对无关知识与已有任务能力的影响。与持续预训练和领域适配相比，这一层次强调修改的针对性、可追踪性及多次编辑后的相互干扰。

对于医学多模态模型，编辑目标既可能涉及文本知识，也可能涉及影像概念与文字描述的对应关系。需要区分更新外部检索资料、修改提示或规则、以及直接修改模型参数三种方式，分别说明修改作用于哪一层、何时生效、能否撤回。新的知识条目应具有可核验来源和版本，涉及临床判断的更新还需要相应专业审核，不能仅以模型生成的新回答作为修改正确性的依据。

评价可以围绕编辑目标的正确性、同义提问与相关影像上的泛化、无关知识和旧任务的保持，以及连续多次编辑后的累积干扰展开。对于不能确定的输入，还应检查模型是否保留适当的不确定性表达和人工复核入口。本文尚未开展上述知识编辑实验，后续需先建立明确的编辑集合、未编辑对照与历史能力测试，再判断局部更新是否带来可接受的能力变化。

\subsection{综合平台支撑下的共同验证与工程实施}

三个层次应共享可追踪的数据与模型版本管理，但保留各自的评价目标。持续预训练主要检验基础表征积累，持续适配主要检验新场景性能与旧场景保持，知识编辑主要检验指定修改的正确性和影响范围。共同的验证流程可记录每次更新使用的资料、访问条件、模型版本及历史测试结果，并在更新不满足要求时保留回退路径。分割、配准和分类可以成为共同的能力检查任务，而不必被强行合并为一个损失或一个总分。

工程实施可先从现有实验流程的统一管理入手，再开展真实多服务器通信与长期数据流验证。需要新增并测试的内容包括任务调度、权限控制、消息和模型版本校验、异常恢复、评价界面及运行监测。真实涂鸦标注、未知任务边界和长期数据流验证应与系统开发分别记录。完成这些工作后，才可能进一步讨论平台运行效果和实际应用价值。

\section{本章小结}
\label{sec:conclusion-chapter-summary}

本章按照第三章基准评测与平台接口、第四章持续配准、第五章弱监督持续分割和第六章联邦持续分类的顺序总结了全文证据，并明确任务范围、历史访问、模拟涂鸦、联邦假设和平台建设状态等限制。面向未来，本文将研究目标扩展到医学多模态大模型持续学习：在数据与表征层开展持续预训练，在任务与场景层开展持续领域适配，在知识与行为层开展持续知识编辑，并由综合平台统一记录数据来源、模型版本、更新条件和历史能力变化。只有在方法效果、资源代价、系统可靠性和医学审核均得到独立验证后，才能进一步讨论长期部署与应用价值。
