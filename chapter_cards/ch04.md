# 第四章 基于梯度子空间融合的无回放联邦持续医学图像分类研究

## 科学问题

## 必须形成的论证链

本地保护无法覆盖其他中心历史
→ 服务器需要汇集跨客户端保护信息
→ 主梯度子空间压缩历史重要方向
→ 服务器融合形成全局保护
→ 正交补投影降低一阶干扰
→ 自适应逐层选择缓解过度保护
→ 多种异质性和资源实验验证取舍

## 禁止声称

- 形式化差分隐私或密码学隐私保证；
- 完全消除灾难性遗忘；
- 无条件适用于异步、任务无关或开放世界环境；
- 在没有统计支持时使用“显著”；
- 把低秩子空间交换写成“无信息泄露”。
