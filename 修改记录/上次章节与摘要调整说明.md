# 本次修改说明

第三章改为“医学影像持续学习评测平台设计”，集中介绍 MedCL 的任务与阶段组织、数据配置、功能模块、评价指标、交互与测试方案，以及对后续研究的支持。原第 3.7 节中被后续章节共用的 A-Dice、BWTR、RMA、E-FWT、WCD、MPE、DRR 定义保留在第三章第 3.5.4 节。

原第 3.7 节中的分割问题定义、三类基准场景、数据与训练设置、密集监督对比实验、任务顺序与回放容量分析、基础模型扩展分析，移入第四章，与原有弱监督分割研究整合。第四章改为“医学影像持续分割基准与弱监督方法研究”，主要结构如下：

- 4.2：持续医学图像分割的问题定义与基准设计。
- 4.3：密集监督持续分割基准评测。
- 4.4—4.5：弱监督持续分割的问题定义与方法。
- 4.6：弱监督持续分割实验与分析。
- 4.7—4.8：综合讨论与本章小结。

重写第四章引言及两部分之间的过渡，突出“密集监督基准评测—监督不足与遗忘问题—弱监督方法”的研究关系。综合讨论区分密集与涂鸦监督、不同回放容量及各项评价指标，避免将跨表差异仅归因于监督形式。

## 四、文件与编译

`main.pdf` 为修改后已编译的论文；`main.tex` 为入口，其余目录保留 LaTeX 源文件、插图和参考文献。

在包含 XeLaTeX、BibTeX 和 latexmk 的 TeX 环境中，在项目根目录运行：

```sh
latexmk -xelatex -interaction=nonstopmode -file-line-error main.tex
```

本次 PDF 使用原模板已有的 Fandol 字体回退设置编译，压缩包不附字体文件。使用本地不同字体重新编译时，换行和页码可能变化。
