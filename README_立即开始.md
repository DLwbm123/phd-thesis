当前稿件已按 2026-08-30 作者提供的预答辩意见完成写作和格式修订。入口为 `main.tex`，详细修订对照见 `handoff/PREDEFENSE_REVISION_20260830.md`，当前状态见 `STATE.md`。

论文题目保持为“面向任务持续演化与训练信息受限的医学影像持续学习研究”。“训练信息受限”指当前阶段不能完整调用监督、历史样本或其他中心的原始数据，不指随机缺失值。

## 当前章节

1. 绪论
2. 医学影像深度学习相关理论与关键技术

第三章先建立场景和评价；第四章在有限回放条件下分别研究涂鸦持续分割与持续配准；第五章进一步研究无历史原始样本回放的联邦分类及工程流程。分割和配准共享研究约束，不是串联流水线；各章数据、指标与存储单位不同，不能据此作跨任务算法排名。

## 工作边界

- 阅读 `AGENTS.md`、`THESIS_CONTRACT.md`、作者协议和当前章节卡后再修改。
- 本轮作者已明确授权正文修订与双端同步；这不等于作者已批准最终学术表达。
- `sources/` 只读，不上传；保留原工作区未提交的实验代码。
- ScribbleCL 当前只报告已核验的 Domain-CL 点估计，不把 Class-CL、Organ-CL 设计写成完成的实验。
- 模拟涂鸦不等于真实医生标注；密集验证标签仍用于模型选择。
- SAMCL 使用有限原始图像对回放；FedSubMerge 不提供形式化隐私保证。
- 第五章系统图明确区分已有单机模拟实验、拟集成管理功能和待验证真实部署。

## 构建与发布

```bash
bash scripts/build_and_audit.sh
python3 scripts/verify_predefense_revision.py
```

图中文字本地化使用已安装的 PyMuPDF 与模板字体，脚本为 `scripts/localize_thesis_figures.py`；它以修订基线提交为输入，不重新绘制实验曲线。

完成本地核验后，先提交并推送 GitHub，再在干净工作区运行：

```bash
bash scripts/sync_latex_to_overleaf.sh
```

该脚本仅同步受管 LaTeX 编译输入，包含字体与随稿 `.bst`，不发布源材料、实验目录、证据账本或构建产物。不得强推或擅自合并到 main。
